# valentine1 💚

A tiny apology website.

| File | What it does |
|------|--------------|
| `index.html` + `style.css` | Main question page (Yes / No) |
| `yes.html` + `yes_style.css` | Celebration page with confetti, counts how many times she said No |
| `no.html` + `no_style.css` | Shown after "No": every No makes the No button bigger, the message sadder and the background gloomier |
| `gifs.js` | **Edit this** to add a different sad gif + message for each "No" stage |
| `common.css` / `common.js` | Shared look, floating hearts, confetti |

## Adding gifs for the No page
Open `gifs.js` and paste a GIF link (or a local file like `gifs/sad1.gif`) into each `gif: ''`.
Empty or broken links automatically show a big emoji instead.

## Run it
Just open `index.html`, or turn on GitHub Pages (Settings → Pages → main branch).
